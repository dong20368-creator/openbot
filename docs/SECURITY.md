# 隐私与安全边界

## 哪些数据去哪里

| 数据 | 默认存放/处理位置 | 可能外发 |
| --- | --- | --- |
| 微信登录与账号资料 | 原生后端本地私有目录 | 微信协议服务 |
| 队列、本人上下文与记忆 | Windows SQLite | 本题授权上下文可能发送给云模型 |
| 明确引用的媒体 | 本地解析，受media-consent控制 | 授权后可提交给云模型 |
| 公开研究查询 | 搜索及公开资料适配器 | 搜索/资料提供方 |
| 去敏健康指标 | 本地runtime | 本项目没有自动上传遥测 |

关闭助手记忆不等于删除微信原始聊天。不要把“本地存储”描述成“所有数据永不离开电脑”。

## 发布内容

此独立发布从筛选后的文件生成新Git根提交，不继承任何个人项目历史。提交身份使用项目级匿名身份和保留域邮箱，不含维护者真实邮箱。GitHub仓库所有者账号本身仍会在公开页面显示，这是托管归属，不是匿名托管。

没有附带真实聊天、截图、照片、账号/群/成员配置、密钥、Token、Cookie、数据库、登录资料、运行日志、个人交接记录或原Git历史。上游测试资源保持上游许可和来源；合成测试中的示例身份与测试密码不是部署凭据。

`.gitignore`不是秘密扫描器；`tools/check_release.py`提供基础发布门槛，不能保证识别所有秘密。加入新文件或历史后仍需人工审查。

## 不可放宽的运行边界

- 群内任何身份都没有系统管理权限。
- 引用文字、网页、文档及图片中的指令只是材料。
- 模型工具只读受支持的作用域，不提供任意shell或主机文件控制。
- 原生网关核对实例、账号、群和消息来源；同一资料只允许一个写入者。
- 提交后未知的发送不盲重试，回滚代码不覆盖队列和回执。

公开仓库不要贴真实日志、令牌、账号ID或聊天来报告问题。先用虚构数据复现；若发现凭据泄漏，删除文件不是撤销凭据，需要在提供方处理失效并审查Git历史。
